O Nosso MVP (Minimum Viable Product)

Para validar a nossa proposta com agilidade, desenvolvemos um MVP funcional focado no núcleo da ferramenta: a ligação entre quem ensina e quem aprende.

Para o Professor: Ferramentas para criar turmas e gerar códigos de acesso exclusivos.
Para o Aluno: Um painel simples para ingressar na turma através do código e começar a resolver desafios.

Todo o sistema foi construído numa arquitetura robusta de API REST com Java e Spring Boot no backend, garantindo segurança e escalabilidade para o futuro.
